# Spider Intelligence

A research and learning project to build an AI system from the ground up. The initial milestone is a small language model trained from random initialization, with our own tokenizer and training pipeline.

## Development

- Code from Android using GitHub or a mobile editor.
- Train experiments in Google Colab.
- Python + PyTorch for the initial neural-network framework.
- No pretrained model weights in the Spider Brain.

## V0.1 goals

1. Character tokenizer
2. Dataset preparation
3. Tiny neural network
4. Training loop
5. Text generation
6. Save/load checkpoint

This small model is a learning prototype, not a capable assistant yet.
